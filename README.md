## Featured projects

### Annotation ExE — image annotation platform
A web platform for labeling images, from microscope slides to drone photos. People make every labeling decision, and the software handles the data work around them. It streams 46,000 × 32,893 px whole-slide images as on-demand tiles at 117 MB peak memory, and imports and exports YOLO, COCO and CVAT.

`React` `TypeScript` `FastAPI` `PostgreSQL + PostGIS` `OpenSlide` `Docker`
**Live demo:** https://annotation-exe.onrender.com/demo/

### Belief-State Learning using DRQN — IEEE Best Paper
A Deep Recurrent Q-Network for decision-making in partially observable environments (POMDPs). It achieved ~23% higher cumulative reward than DQN across 16 independent seeds.

`Python` `PyTorch` `LSTM` `Reinforcement Learning`
**Code:** https://github.com/AnupamMI/DRQN_POMDP_Project

### CareLink — healthcare companion · 1st Place, APPTHETICS 3.0
A cross-platform health app combining medication tracking, fitness monitoring, health analytics and an AI assistant, with the CareScore wellness metric.

`React Native` `Expo` `TypeScript`
**Code:** https://github.com/AnupamMI/CareLink

### SignTalk — sign language translation glove · Best Socially Relevant Project
A wearable that turns sign language gestures into real-time text using multi-sensor fusion and embedded processing.

`C++` `Arduino` `IoT` `Sensor Fusion`
**Code:** https://github.com/AnupamMI/Smart-Glove-Safety-Device

### AI Skill Gap Radar
An NLP tool that parses resumes, finds skill gaps against target roles and recommends learning paths.

`Python` `NLP` `Machine Learning`
**Code:** https://github.com/AnupamMI/skill-gap-radar
